## 🚀 RUN LOCALLY

Want to explore or run the portfolio on your own machine?

**Prerequisites:** Node.js and npm.

```bash
# 1. Clone the repository
git clone https://github.com/harshalisalve24-dev/Harshali---Portfolio.git

# 2. Enter the project directory
cd Harshali---Portfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev

# 5. Generate a production build
npm run build
```

The production-ready files are generated in `dist/`.
